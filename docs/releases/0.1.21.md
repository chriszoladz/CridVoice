# CridVoice 0.1.21

This update focuses on keeping your words and making insertion more reliable.

- Substantive Text rewrites receive a separate meaning check on the selected model/provider. Failed checks use your original transcript.
- **Original words**, in Writing styles, bypasses AI rewriting for fast normal dictation. The setup and warming plan skips unused cleanup components.
- Cleanup prompts favor your wording, and default slang has an additional wording guard.
- The recording preview appears without activating its window and avoids repeated show/hide calls during audio updates.
- Focus validation supports a recreated editor with no AutomationId when its unique editor host and removal of the old field can be verified. Password fields, other windows and ambiguous targets remain blocked.
- Normal Text dictation can insert its original transcript when cleanup is unavailable. Failed code generation and selected-text edits retain their review safeguards.
- Final local recognition uses deterministic decoding and vocabulary-only prompting without conditioning each segment on an earlier segment.

Meaning checks can add finishing latency and an extra request when using a provider. They reduce unwanted rewriting but do not guarantee perfect recognition or editing. No personal settings or model files are replaced by this source update.
